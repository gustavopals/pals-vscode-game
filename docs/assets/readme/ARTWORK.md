# Artes do README

Ilustrações conceituais geradas em 2026-10-01 com a ferramenta integrada `image_gen` (modo built-in). Apresentam o universo planejado de Lords of the Guild; não são capturas de gameplay nem representam a interface implementada.

- [Capa — hero.png](hero.png): vila de Pedra Alta entre o outono e o inverno.
- [Estações — seasons.png](seasons.png): quatro vistas sazonais; usa a capa como referência de estilo e arquitetura.

Os arquivos finais foram copiados para este diretório sem edição posterior. Os prompts abaixo são os textos completos enviados à ferramenta.

## Capa

```text
Use case: stylized-concept.
Asset type: original illustrated hero cover for the GitHub portfolio README of the game "Lords of the Guild".
Primary request: a polished, memorable medieval strategy-game key art, an intimate realm called Pedra Alta governed in short coffee breaks, preparing for winter.
Scene: a modest stone keep and small timber-roofed village perched on a rocky highland, terraced fields, a sawmill near a pine forest, a winding path leading toward its warm illuminated gate. Mountain ridges fade into the distance; late-autumn sunset touches the village while a cold winter storm approaches across the far mountains. A few tiny travelers convey scale. No modern objects, no editor interface.
Style: sophisticated hand-painted fantasy environment illustration, rich textured brushwork with crisp architectural focal detail, atmospheric depth, restrained cinematic light; premium indie-game artbook cover.
Composition: wide panoramic 2:1 landscape, approximately 2048 x 1024. Strong readable silhouette of the keep and village in the middle, detailed landscape across the full width, quieter dark atmospheric sky above for typography. Elegant small ornamental linework around the title only; no ornamental outer border.
Text (verbatim): "LORDS OF THE GUILD". Large, beautifully spaced ivory serif capitals in the upper sky, readable at GitHub README width. This exact title is the only text.
Constraints: one continuous illustration, full bleed, no screenshot, no mock browser, no fake UI, no badges, no watermark, no additional words. Keep the village human-scale, inviting yet resilient, with warm light against cool distant winter.
```
